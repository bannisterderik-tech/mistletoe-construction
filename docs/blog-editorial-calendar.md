- **Cadence:** publish one post mid-month and one late-month. The first post each month should be the seasonal/timely one; the second can be evergreen-with-a-local-angle.
- **Length:** 600–1,000 words. Real, plain-spoken, family-business voice. First person ("our crew," "we get called about…").
- **Internal linking:** each post links to 1–2 relevant `/guides/` pages and to `/instant-quote.html`. Suggested links are noted per post.
- **CTA block:** close every post with the instant-estimate button + call/text line. Mention the $500-off / free-gutters offer where it fits naturally (booking and cost-adjacent posts), not on every safety/DIY piece.
- **Trust footer:** every post should surface "Oregon CCB #255729 · Owens Corning contractor · family-owned in Riddle."
- **Refreshable posts** (marked ♻): update the year and re-publish annually — they're built to be seasonal evergreen.
